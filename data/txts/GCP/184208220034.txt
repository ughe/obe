2234. NICOLAS SUISSE was indicted for stealing, on the 1st of
March, at St. George Hanover-square, 30 securities, called coupons, each
entitling the bearer to 500 francs, in the French Five per Cent. Rentes,
value 6001. ; 3 other coupons, value 601.; 2 other coupons, value 201.; 1
other coupon, value 201.; 3 other coupons, value 60l.; 16 other coupons, value
3201. ; 2 other coupons, value 2001. ; 2 other coupons, value 601.; 2 other
coupons, value 401. ; 3 other coupons, value 601. ; 4 other coupons, value
401. ; 1 other coupon, value 6l.; and 1 other coupon, value 21.; the pro-
perty of Francis Charles, Marquis of Hertford, his master, in his dwelling.
house.-Other Counts, varying the description of the securities, and the
manner of stating the charge.
Messrs. KELLY, Phillips, and Bopkin, conducted the Prosecution.
