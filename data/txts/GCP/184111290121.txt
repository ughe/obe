tumblers, value 6s. ; 1 finger-glass, value 1s. ; 1 jelly-glass, value 18.; 5

2 bandkerchiefs, value 58. ; 2 blankets, value 158. ; 2 sheets, valge 10$. ;
2 pillows, value 10$. ; 1 bolster, value 108. ; 1 bed, value 6l. ; 1 mattress,
value 21. ; 2lbs. weight of soap, value 1s.; and 4lbs. weight of candles,
value 28.; the goods of Abraham Slowman, her master; and ALFRED
WINSLOW, for receiving the same, well knowing them to have been
stolen ; against the Statute, &c.-3rd Count, for receiving them of a cer
tain evil-disposed person ; to which
FITZGERALD pleaded GUILTY. Aged 21.-Recommended to mercy,
